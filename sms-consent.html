SMS Consent Policy

Quotable Wisdom — RememberMe Feature

Overview

Quotable Wisdom is a quotes and daily inspiration app. The core app — browsing quotes, saving favorites, and receiving daily quote notifications — does not require SMS consent and is fully available without it.

The RememberMe feature is an optional, separate feature that allows a user to schedule a personal text message to someone they know on a meaningful date (birthday, anniversary, holiday). SMS use is entirely voluntary — users who do not want to send SMS messages simply do not use RememberMe.

In-App Consent Checkbox Optional Feature

When a user chooses to use RememberMe and schedule an SMS, they are presented with the following unchecked consent checkbox. The user must actively check this box themselves before the message can be saved. The checkbox is never pre-selected.

As shown to the user inside the app (unchecked by default):

I confirm this person has agreed to receive a personal message from me on this date.

The checkbox is unchecked by default. The user must tap to check it. This is an optional feature — users may use the full Quotable Wisdom app without ever interacting with RememberMe or SMS.

Who Receives Messages

Messages are personal greetings from one individual to another known contact — not marketing, not promotional, and not bulk messaging. The sender personally knows the recipient and has obtained their consent prior to scheduling.

Message Content

All messages are short personal greetings. Example:

"Happy Birthday! Thinking of you today. — John, via Quotable Wisdom"

Messages contain no advertising, no promotional offers, no links, and no unsolicited content. Each message is a one-time send on a date chosen by the sender.

Opt-Out

Recipients may reply STOP at any time to stop receiving messages from the sender via Quotable Wisdom. Reply HELP for support. Message and data rates may apply.
